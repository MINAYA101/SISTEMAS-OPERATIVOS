📘 Memoria Virtual
🖥️ ➕ 💾

Técnica que permite ejecutar procesos más grandes que la RAM física, usando espacio en disco como extensión.

✅ Ilusión de memoria continua y abundante.
✅ Direcciones lógicas → direcciones físicas mediante MMU.

🔄 Swap
💿 ⇄ 🧠

Movimiento temporal de procesos/páginas entre memoria principal y espacio de swap (disco).

Proceso activo ⏩ Área swap (disco)

📉 Swap-in / Swap-out: libera RAM cuando hay presión de memoria, mejora multiprogramación.

⚠️ El swapping puede afectar rendimiento si es excesivo (thrashing).

📌 Datos Clave
  • MMU: traduce direcciones virtuales → físicas.
  • Paginación: elimina fragmentación externa, puede causar interna (última página).
  • Swap: área en disco, más lenta que RAM (1000x).
  • Thrashing: exceso de swapping, rendimiento colapsa.
🎯 Objetivo: maximizar multiprogramación con recursos limitados
